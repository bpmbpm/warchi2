## wArchi Browser — ver1

Браузерная реализация репозитория архитектуры предприятия [warchi.ru](https://warchi.ru/).

## Описание

Полная копия функционала warchi.ru на браузерном JavaScript, без серверной части и СУБД. Данные хранятся в `localStorage` браузера. Развёртывание — GitHub Pages.

## Возможности

- **Редактор диаграмм** — Canvas-редактор с узлами и связями, drag-and-drop, масштабирование, панорамирование
- **Матрица связей компонентов** — 2D-таблица зависимостей между типами компонентов, с тепловой картой и детализацией
- **Тестовая модель** — 14 узлов ArchiMate (Приложение, Бизнес, Данные, Инфраструктура, Мотивация) + 14 связей
- **Нотации** — ArchiMate 3.2, C4 Model, BPMN 2.0, UML
- **Экспорт/импорт** — JSON, SVG, PNG
- **Журнал событий** — расширяемое окно лога в нижней части экрана (тянуть за верхний край или угол)
- **Документация** — на русском языке, встроена в приложение

## Доступ

- Пользователь: `user1` (авторизация исключена по условию задачи)
- Все действия выполняются без входа в систему

## Технологии

- Чистый HTML + CSS + JavaScript (без фреймворков, без сборки)
- `localStorage` для хранения данных
- Canvas API для рисования диаграмм
- Один файл `index.html`

## Использование

Открыть `index.html` в браузере или перейти на GitHub Pages.

### Быстрый старт

1. Раздел **Модели** → **Открыть** напротив тестовой модели
2. Перетащите компоненты из палитры (снизу левой панели) на диаграмму
3. Правой кнопкой по узлу → **Добавить связь**
4. Раздел **Матрица связей** → выбрать модель

## Известные ограничения

Подробнее: [problem_v1.md](problem_v1.md)

- Нет серверной части (данные в localStorage, не в PostgreSQL)
- Нет многопользовательского режима (только user1)
- Canvas-рендерер упрощён по сравнению с оригинальным Papirus
- Нет WebSocket (только локальные данные)
